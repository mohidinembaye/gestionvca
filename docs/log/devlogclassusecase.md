# DEVLOG — Journal de développement

## 14/08/2026 — Ajout des diagrammes UML

### Objectif

Documenter la conception du projet à travers des diagrammes UML avant la mise en œuvre du code.

### Travail réalisé

Ajout des diagrammes suivants :

* Diagramme de cas d'utilisation
* Diagramme de classes orienté objet (POO)

Le diagramme de cas d'utilisation permet d'identifier les acteurs du système ainsi que les principales fonctionnalités auxquelles ils ont accès.

Le diagramme de classes permet de représenter la structure du système en identifiant les classes, leurs attributs, leurs méthodes et les relations entre elles.

### Notions apprises

* Identification des acteurs d'un système
* Identification des cas d'utilisation
* Modélisation UML
* Diagramme de cas d'utilisation
* Diagramme de classes
* Classes, attributs et méthodes
* Relations entre les classes
* Conception orientée objet (POO)

### Commit

```bash
git commit -m "docs(uml): ajout des diagrammes de cas d'utilisation et de classes POO"
```

### Résultat

La conception UML du projet est documentée et sert de référence pour la suite du développement.
